# 손해율 월말 집계 및 워드 리포트 자동화

## 집계 정의 (기준월 202609 예시)

| 지표 | 당기 | 비교기간 (동기간, 1개월 전) |
|---|---|---|
| **UY 누적** (UY26.1~9 누적) | 계약 202601~202609, 마감 202609까지 누적 | 계약 202512~202608, 마감 202608까지 누적 |
| **UY 당월** (UY26.9 당월) | 계약 202601~202609, 마감 202609 한 달 | 계약 202512~202608, 마감 202608 한 달 |
| 전기간 누적 (출시 이후) | 계약 202505~202609, 마감 202609까지 누적 | 계약 202505~202608, 마감 202608까지 누적 |

- UY 시작월 = 기준연도 1월 (자동), 비교기간 = 계약 구간과 마감월을 1개월 앞당김 (자동)
- 손해액 = 지급보험금합계 + 지급비금변동분 합계, 손해율 = 손해액 ÷ 위험보험료
- 위험보험료 증감률 = 당기 ÷ 비교 − 1, 손해율 증감(p) = 당기 손해율 − 비교 손해율
- 손해율 Top 20 = 위험보험료 비중 0.05% 이상 담보 중 손해율 상위
- 년월 형식: `202609` (6자리 숫자)

## 내부망 (파이썬 없음): 엑셀 수식 + VBA

반입 파일: `excel/손해율_집계.xlsx`, `excel/report_macro.bas` (외부망에서 `python build_excel.py`로 생성)

### 매월 작업
1. `실행` 시트 노란 칸에 마감 기준월 `202609` 입력 (UY 구간·비교기간 자동)
2. 매크로 `LoadRawData` → 로데이터 파일 선택 (출시월~기준월 마감 전체, 기존 데이터 자동 삭제·형식 정리)
3. `실행` 시트 데이터 점검 종합 상태 확인
4. 매크로 `MakeWordReport` → `손해율_결산리포트_202609.docx` 생성

매크로 최초 1회 설치: Alt+F11 → 파일 → 파일 가져오기 → `report_macro.bas` → `.xlsm`으로 저장.
매크로 없이도 집계는 동작한다 (raw_data 비우고 A1에 붙여넣기 → 요약/Top20 표 복사).

### 깨지지 않게 한 장치
- raw_data에는 원본 10개 열만 (보조 수식 열 없음) → 행 수가 바뀌어도 수정 불필요
- 담보 마스터 최대 1,000개, 대급부 최대 20종 자동 반영
- 담보코드 텍스트/숫자 형식이 달라도 매칭
- 매크로가 텍스트 년월(`2026.09`, `'202609`, 날짜형)·텍스트 금액(`1,234`, 빈칸)을 숫자로, 코드 공백을 정리
- `실행` 시트 데이터 점검표가 입력값·숫자 형식·열 순서·기준월/비교 마감월 데이터 유무·미매핑·중복 등을 검사,
  `오류`면 매크로가 리포트 생성을 중단

## 외부망 검증용 (파이썬)

```bash
pip install -r requirements.txt
python 1_generate_dummy.py              # 더미: 마스터 545건 + 로데이터(계약 202505~, 마감 ~202609)
python main_pipeline.py --base 202609   # 워드 리포트 + 담보별 집계 CSV (output/)
python build_excel.py                   # 내부망 반입용 엑셀 템플릿 생성
```

엑셀 수식 결과는 파이썬 파이프라인과 담보 단위로 대조해 일치를 확인한다.
