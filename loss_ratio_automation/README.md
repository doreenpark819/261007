# 손해율 월말 보고서 자동화 (엑셀 수식 + VBA → 워드)

내부망(파이썬 없음)에서 **엑셀 하나로 집계하고, 매크로 한 번으로 워드 보고서까지** 만든다.
레이아웃은 기존 수작업 보고서(2. 손해율 현황 / 별첨 1. 급부별 손해율)를 그대로 따른다.

## 반입 파일
| 파일 | 내용 |
|---|---|
| `excel/손해율_보고서.xlsx` | 수식 기반 집계 + 보고서 레이아웃 (더미 데이터 포함) |
| `excel/report_macro.bas` | VBA (CP949): `LoadRawData` 로데이터 불러오기, `MakeWordReport` 워드 생성 |

매크로 최초 1회 설치: Alt+F11 → 파일 → 파일 가져오기 → `report_macro.bas` → `.xlsm`으로 저장.

## 매월 작업
1. `실행` 시트 노란 칸에 마감 기준월 입력 (예: `202608`) → 구간·라벨·표 제목 모두 자동
2. `LoadRawData` → 로데이터 파일 선택 (최초판매월 마감분 ~ 기준월 마감분 전체)
3. `실행` 시트 데이터 점검 종합 상태 확인, `보고서` 시트에서 숫자 확인
4. `MakeWordReport` → `손해율_보고서_202608.docx` 생성

## 입력 데이터
- `raw_data`: 계약년월 | 마감년월 | 주상품코드 | 특약상품코드 | 경과개월수 | 심사유형 | 담보코드 | 위험보험료 합계 | 지급보험금합계 | 지급비금변동분 합계 | **건수(선택)**
- `code_master`: 담보코드 | 담보명(= 보고서의 급부, 같은 이름끼리 합산) | 대급부명(표3 구분: 암진단·암이외진단…) | 구분(표1·2 구분: 진단…, 빈칸이면 대급부명) | 고당대통(Y)

## 집계 정의 (기준월 202608 예시)
| 항목 | 정의 |
|---|---|
| CY'26.8 / CY'26.7 | 마감년월 = 202608 / 202607 (계약년월 무관) |
| CY 누적 (*~26.7) | 마감년월 최초판매월(202506)~202608 (~202607) |
| UY 당월 '26.8 / '26.7 | 계약 202601~202608의 202608 마감 / 계약 202512~202607의 202607 마감 |
| UY 누적 '26.1~8 / '25.12~'26.7 | 계약 202601~202608의 202608까지 누계 / 계약 202512~202607의 202607까지 누계 |
| 급부별 누적손해율 | 최초판매월~기준월 마감 누계 |
| 손해액 | 지급보험금 + 지급비금변동분 |
| 증감·比 | 손해율은 %p 차이, 금액은 백만원 차이, 음수는 △ |

## 급부별 표 선정
- 표(1) 주요급부: UY 손해율 상위 N(기본 20, 고당대통 제외) + 고당대통 급부(구분 '기타')
  - 빨강 = UY 동기간 대비 악화 / 파랑 = 동기간은 개선이나 누적손해율(전월 대비)만 악화
  - 합계 3행: 주요급부 평균, 전급부 평균, 전급부 대비 위험보험료 비중
- 표(2) 그외: 표(1)에 없는 급부 중 UY 손해율 100% 초과 (빨강 악화 / 파랑 감소)
- 표(3) 위험보험료 상위 15: UY 위험보험료 순위, 누적 위험보험료·P/F·건수·누적손해율 표시
- 구분 표시 순서·상위 N·기준값은 `실행` 시트에서 변경
